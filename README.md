# IBM-HR-Analytics-Attrition-Insights
HR Data Analysis project using Python, SQL, and Power BI to analyze employee attrition based on department, salary, and satisfaction levels.

# Project Overview:
This project analyzes employee data to understand why people leave the organization. By looking at factors like salary, department, and work environment, the analysis provides data-driven insights to help improve employee retention.

# Tools Used:
* Python: For cleaning the HR dataset and initial data exploration.
* MySQL: To perform complex queries for attrition rates and departmental stats.
* Power BI: To create an interactive dashboard for visual storytelling.

# Key Metrics & Visuals:
* Total Attrition: Overview of the company's turnover rate.
* Department-wise Analysis: Comparing attrition across R&D, Sales, and HR.
* Yearly Trends: Tracking how attrition changes over time.
* Salary-wise Distribution: Analyzing the link between income levels and employees leaving.
* Environment Satisfaction: Understanding how the work atmosphere affects employee stay-or-leave decisions.

# Files in Repository:
* hr_analysis.py (Python Code)
* hr_attrition_analysis_queries.sql.sql (SQL File)
* HR Employee Attrition Dashboard.pbix (Power BI Dashboard)
